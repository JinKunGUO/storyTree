## 一、产品认知：我们在推什么

### 一句话定位

**StoryTree 是一个"分支式 AI 协作小说创作平台"——写故事像种树，每个选择都长出新的世界。**

### 产品本质（三个交叉点）

| 维度 | 我们做到 | 竞品现状 |
|------|---------|---------|
| **AI 创作** | 立项书/大纲/仿写/模板/续写/润色/插图，7 种 AI 能力 | 秘塔、笔灵等是纯工具，无社区无分支 |
| **分支叙事** | 故事树可视化，每个节点可分叉，读者自选路径阅读 | 橙光有分支但无 AI 且创作门槛极高 |
| **协作共创** | 协作者续写分支、协作申请、多人共创一棵树 | 网文平台都是单人独写，AI Dungeon 无协作且是英文市场 |

**竞争结论**：中文市场无任何平台同时占据这三点，属于真正的品类空白，有 2-3 年窗口期。

### 核心特色清单（传播弹药库）

推广中可反复使用的卖点，按传播力排序：

1. **"每个选择，都长出新的世界"**——品牌 slogan，适合所有物料
2. **AI 十分钟写出一棵故事树**——降低创作心理门槛，最易传播的演示点
3. **多结局小说**——读者视角卖点："一个故事读了 3 遍，每次结局不一样"
4. **和朋友写同一棵树**——协作卖点，天然适合社交裂变场景
5. **可视化故事树**——树形分支图本身就是绝佳视觉素材（截图即内容）
6. **7 种 AI 姿势**：不会写？AI 帮你出立项书、列大纲、仿你喜欢的作家风格、直接续写、润色、配插图
7. **积分 + 徽章 + 追更**——游戏化留人机制，对标追更网文的用户习惯
8. **公版经典种子内容**（红楼梦、围城、边城）——冷启动内容底气，可做"用 AI 给红楼梦写分支结局"话题
9. **夜空视觉语言**——星点+生长树的品牌设计，截图颜值高，适配小红书/小红书式种草平台
10. **微信一键登录 + 小程序**——转化链路短

### 用户价值主张分层

- **对创作者**：不会写 → AI 帮你写；写得好 → 读者替你的分支投票追更
- **对读者**：不再被动读线性故事，你的选择决定剧情走向
- **对社群玩家**：语C/共创文圈的升级形态，协作写树自带社交货币

## 二、目标人群画像

### 人群 A：同人/互动叙事爱好者（主力，冷启动核心）

- 18-30 岁，活跃于 LOFTER、半次元、B站、橙光
- 特征：有创作欲望但被"写不好"劝退，或已在写同人寻找新形态
- 切入话术：「不用学引擎，AI 帮你把同人多结局写出来」
- 对应功能：模板创作、风格仿写、分支阅读

### 人群 B：写作类 KOC 与写作课学员（中期放大器）

- 写作博主、高校创意写作课、写作训练营学员
- 特征：需要工具提效 + 需要展示素材
- 切入话术：「AI 立项书 + 大纲，写作课作业效率翻倍」
- 对应功能：AI 立项书、大纲、续写字数控制（200-5000 字）

### 人群 C：泛内容消费者（规模化阶段）

- 短视频/小红书重度用户，爱看互动短剧、"选择你的人生"类内容
- 特征：不创作但愿意为好故事停留，是流量与会员转化的基数
- 切入话术：「这个网站的故事，你自己选剧情走向」
- 对应功能：分支阅读、追更、章节收藏

### 优先级

**A > B > C**。冷启动期全力打 A（创作者带内容），增长期用 B 放大声量，规模化期靠 C 撑数据。

## 三、核心传播信息（话术体系）

### 品牌层（长期统一）

- **主口号**：每个选择，都长出新的世界
- **副口号**：写故事像种树
- **视觉锤**：夜空 + 星点 + 金色分支生长树（全平台统一头像/封面/物料）

### 场景层（按渠道选用）

| 场景 | 话术 | 适用 |
|------|------|------|
| 拉新演示 | "AI 10 分钟写出一棵多结局小说" | 视频/直播/教程 |
| 创作者痛点 | "卡文了？让 AI 续写三个方向你自己挑" | 写作社群 |
| 读者种草 | "我读了 3 遍，每次结局都不一样" | 小红书/B站 |

## 五、渠道打法

### 1. 小红书（冷启动主力，细则见冷启动手册）

- **为什么是主力**：18-30 女性用户与互动小说人群高度重合；"故事树截图 + AI 创作过程"天然是图文笔记形态；搜索心智已建立（"AI 写小说"关键词竞争空白）
- **打法要点**：
  - 每篇笔记必须带**故事树可视化截图**（这是别人没有的视觉差异点）
  - 三类内容轮换：产品展示 / 创作过程 / 读者视角（手动配比 4:3:3）
  - 评论区置顶引导语：「站内搜 XX 直接玩，注册就送 50 积分」
- **衡量指标**：笔记曝光 → 注册转化率（用邀请码追踪不同笔记的转化）

### 2. 写作类社群（QQ 群/微信群，冷启动裂变源）

- 邀请码定向投放：邀请人 +25 积分、被邀请人 +50 积分（已内置）
- **进阶玩法**：策划"阶梯解锁"——邀请 3 人解锁高级 AI 功能使用权（需产品侧配置）
- 群内人设：以"一起写故事的工具人"自居，发分支故事片段求群友投票走向（互动即传播）

### 3. B站（增长期主力视频渠道）

- 内容形态：
  - 教程类：「用 AI 写出你的第一本互动小说」（全流程录屏，树形图是视觉高潮）
  - 挑战类：「让 AI 仿写鲁迅风格写悬疑，3 个结局你们选」
  - 共创类：「和粉丝一起写一棵故事树」系列（把协作过程做成连载）
- 发布节奏：每周 1-2 更，前 5 期不求量求完播率

### 4. 知乎/豆瓣（SEO 资产，长尾流量）

- 回答存量问题："如何写互动小说""AI 写作工具推荐""橙光替代品"
- 自建问题：「有哪些支持多结局/分支叙事的小说平台？」（品类空白 = 该问题的最佳答案就是我们）
- 故事详情页已具备 SEO 基础（标题/描述），确保 robots 与结构化数据到位

### 5. 私域（微信生态，转化承接）

- 公众号：故事连载（每周把平台优质分支章节整理成推送，结尾"点击阅读树的原版"）
- 小程序：已支持，作为微信内转化的落地页（避免外链跳转损耗）
- 群运营：创作者群（征集反馈 + 内测新功能）、读者群（分支投票玩法）

### 6. 线下/跨界（规模化阶段）

- 高校创意写作课：协作分支叙事天然适合课堂小组作业场景
- 独立游戏开发者：故事树 = 文字冒险游戏的剧本引擎，可孵化合作
- 有声书/短剧：分支故事是互动短剧的内容母体

## 六、内容策略：让产品自己成为内容工厂

### 示范内容矩阵（冷启动弹药）

| 类型 | 数量 | 选题示例 |
|------|------|---------|
| 悬疑推理 | 1-2 棵 | 「凶手是谁？3 条线索 3 个结局」 |
| 恋爱抉择 | 1 棵 | 「表白还是错过？你来决定走向」 |
| 奇幻冒险 | 1 棵 | 「勇者的选择：每步通向不同命运」 |
| 经典二创 | 1 棵 | 「AI 续写红楼梦第 121 回」（话题型） |

每棵树 3-5 个分支节点起步，保证新用户进站"有东西可读、有分支可选"。

### 内容复用机制（一次创作，多平台分发）

```
一棵优质故事树
 ├─ 树形截图 → 小红书图文 / 微博配图
 ├─ 分支片段 → 公众号连载 / 知乎回答例证
 ├─ 创作录屏 → B站教程素材
 └─ 结局投票 → 社群互动话题 / 私聊裂变钩子
```

### 创作挑战赛（增长期发动机）

- 「7 天写出你的第一棵故事树」：完成即送高额积分 + 挑战徽章
- 月度热门故事树榜单：作者获流量倾斜
- 参赛作品自动成为平台内容池，一鱼两吃

## 七、转化路径设计（用户旅程）

### 新用户首次到访的黄金 5 分钟

产品已内置完整引导链路，推广侧要做的是**让每个入口都通向这条路径**：

```
落地（首页夜空视觉抓眼球）
 → 新手引导（欢迎弹窗任务清单：逛发现页/理解故事树/创建故事/发布章节）
 → 体验分支阅读（发现页搜索建议直接推荐热门关键词）
 → 低门槛创作（AI 立项书 5 分钟出一棵树雏形）
 → 首次发布（里程碑徽章 + 积分奖励即时反馈）
```

### 关键转化钩子（产品已具备，推广话术直接引用）

| 节点 | 钩子 | 推广话术 |
|------|------|---------|
| 注册 | 邀请码 +50 积分 | "注册就送积分" |
| 首次创作 | AI 免费额度 | "第一次用 AI 写小说免费" |
| 首次发布 | 里程碑徽章 + 创作积分 | "发布第一个章节就解锁徽章" |
| 邀请好友 | +25 积分/人 | "邀请 3 人解锁更多 AI 额度" |
| 深度使用 | 追更/协作 | "你的分支有人追更了"（留存通知） |

### 转化漏斗监控指标

注册 → 完成新手引导 → 首次阅读分支 → 首次创建故事 → 首次发布章节 → 7 日回访

每一步的转化率决定上一环节的推广效率，需在管理后台（admin 数据仪表盘）持续观测。

### 北极星指标

**周活跃创作者数（本周发布过章节的用户）**——内容社区的唯一生死指标。

## 十、风险与注意事项

1. **冷启动鸡生蛋**：没有内容就没有用户——所有推广必须以示范内容为前提，**先备弹药再开枪**（参照冷启动手册 Week 1）
2. **AI 成本失控**：AI 配额体系已内置，推广话术避免"无限免费 AI"类承诺；早期可限制免费额度引导升级
3. **合规红线**：
   - AI 生成内容需遵守生成式 AI 管理规定（已有内容审核系统，保持开启）
   - 仿写功能推广中不点名"仿写 XX 在世作家"，用公版经典（鲁迅、张爱玲等已故作家）做演示更安全
   - 备案信息（浙ICP）在推广物料中如实展示
4. **不过度承诺**：AI 生成质量有波动，话术用"AI 帮你"而非"AI 替你"，管理预期避免差评
5. **小步放量**：服务器与 AI API 并发能力有限，大流量投放前先压测（已有 AI 并发优化方案文档）
6. **MIT 开源协议风险**：项目当前采用 MIT 协议，任何公司/团队均可 fork 代码并商业化运营，无法阻止。如计划商业化，应尽早改为 AGPL-3.0 或 BSL 1.1 等限制性协议，或采用"开放核心"模式（核心框架开源，商业功能闭源）。详见《项目全景分析与竞争策略》归档文档

## 十二、商业化路径

### 现有收入结构（已实现）

| 收入来源 | 定价 | 状态 |
|---------|------|------|
| 会员订阅 | ¥30/月 ~ ¥200/年 | ✅ 已上线 |
| 积分充值 | ¥9.9 ~ ¥160 | ✅ 已上线 |
| AI功能消耗 | 续写10积分/次，润色3积分/次，插图20积分/次 | ✅ 已上线 |

### 建议新增收入源

1. **内容付费（最高优先级）**
   - 付费分支解锁：作者可设置部分精彩分支为"付费阅读"（1-5积分/分支）
   - 打赏机制：读者向创作者打赏（平台抽成 20%）
   - 预估：若 5% 用户付费，ARPU ¥30/月 → 1万用户即可月入 ¥15,000

2. **AI 增值服务（中期）**
   - 高级AI模型：提供更高质量的AI续写，会员专享
   - AI插图升级：角色一致性插图包（按套收费）
   - AI有声书生成：将故事树自动转为有声内容

3. **IP 衍生（长期）**
   - 优质故事树 → 互动短剧脚本 → 授权给短剧公司
   - 故事树 → 文字冒险游戏 → 上架Steam/TapTap
   - 与出版社合作，将人气故事的"最佳路径"出版为实体书

4. **B端服务**
   - 教育版：面向学校创意写作课程的协作写作平台（按班级收费）
